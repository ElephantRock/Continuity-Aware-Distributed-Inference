# C7.3a State-size review resolution

This addendum records the bounded pre-result review resolution for State-size provenance. No P2/P3 comparative result was inspected.

The closed C6.4f acceptance record carries, for both accepted hardware profiles, `state_fixed_bytes = 0`, `state_bytes_per_token = 524288`, and `memory_capacity_bytes = 85899345920`. C6.4g consumes those accepted state/memory scalars. Therefore C7.3a freezes its predeclared C7.1 reference design point at `state_tokens = 16`, classified P-SRC4, and maps it through the accepted C6.4f source-model-derived State-memory mechanics to exactly `8,388,608` bytes. The evidence class remains `SIMULATED_SOURCE_MODEL_DERIVED_P_SRC2`; this is not direct hardware measurement.

An intermediate source-predictor configuration containing a nonzero fixed value is not the accepted C6.4f State-memory record and is not used by C7.3.

The retention manifest now fails closed unless all three State-size bindings match the frozen protocol: the canonical State-size-map fingerprint, `state_tokens = 16`, and `state_bytes = 8,388,608`. This removes State size as a result-dependent degree of freedom before C7.3b/C7.3c execution. Any later State-size sensitivity requires a new pre-result protocol version.
