## Statistics

Ratio metrics are ratio-of-sums. A zero aggregate denominator, including a zero-denominator bootstrap resample, fails closed as `INSUFFICIENT_METRIC_DENOMINATOR`.

The executor caches the already-frozen SHA-256 bootstrap index tuple by `(sample_size, resample_index)`. This is only an implementation optimization: the generated index schedule, paired Program clusters, ratio recomputation, and Type-7 percentile rule are unchanged.

Two exact algebraic identities are used to avoid redundant bootstrap work:

```text
WSR = 1 - USR
CCR = RR
```

The first follows from the C7.3b exhaustive partition of classified resident byte-time into useful and wasted intervals. The second is exact only in this C7.3c construction because every eligible opportunity is the same frozen 1024-token prefix. Therefore the WSR comparison is the sign-reversed USR comparison, and the CCR comparison is copied from RR. This changes no statistic and reinforces the frozen rule that RR and CCR are correlated/redundant, not independent corroboration.

P2 Tool-Return TTFT is evaluated only on the common policy-independent returning-Program subset. Fewer than eight returning Programs is descriptive only and cannot support H5.

## H5 adjudication

Primary comparators are exactly:

```text
LRU
FIXED_TTL(5s)
SESSION_PINNING
```

For USR, RR, or CCR, a support cell must be capacity-comparable for all 64 Programs, semantically valid, and have a favorable paired 95% interval versus all three comparators.

For P2 Tool-Return TTFT, the same requirement must hold on both accepted C6 hardware-profile strata and the returning-Program count must satisfy the frozen minimum.

A positive H5 decision requires a connected component of at least two immediately adjacent support cells on one frozen primary surface for the same support metric. Otherwise the decision is exactly:

```text
NOT_SUPPORTED_WITHIN_DECLARED_PHASE_SPACE
```

A positive result is labeled `SUPPORTED_WITHIN_DECLARED_PHASE_SPACE` only as the complement of the frozen null decision; it does not broaden the hypothesis or evidence class.
