## 1. Purpose and semantic boundary

C8 moves CADI from deterministic/simulated execution to real CPU distributed execution. C8.1 freezes the implementation and measurement contract before C8.2 and before any headline practicality result exists.

The existing Continuity Core remains authoritative. C8 may distribute physical execution and observation, but it does not distribute semantic authority. K1–K5, State lineage, Attempt fencing, Binding epochs, Evidence authority, and reconciliation semantics remain unchanged.

Out of scope are consensus, Byzantine behavior, synchronized-clock safety, GPU inference benchmarking, production Kubernetes integration, and multi-region control.

## 2. Process roles and actual process boundary

The reference prototype has:

```text
CONTROL_PLANE_AUTHORITY
WORKER
FAULT_TRANSPORT_HARNESS
```

Only `CONTROL_PLANE_AUTHORITY` may commit authoritative Continuity mutations. Workers execute physical work and emit observations/completions. The fault/transport harness controls delivery behavior but cannot forge semantic identity or directly mutate authoritative state.

A rankable run records actual OS process identities:

```text
authority_pid
worker_pids
fault_harness_pid
```

The authority PID, every worker PID, and the fault-harness PID must be distinct. At least one worker process is required. Merely claiming a process count is insufficient evidence of a real process boundary.

A separate State-service process is not frozen in C8.1. C8.2 may add one only through an explicit pre-measurement protocol revision if the required State-loss/migration traces cannot otherwise be represented faithfully.

## 3. Reference transport and message envelope

Reference transport:

```text
LOOPBACK_TCP_LENGTH_PREFIXED_CANONICAL_JSON_V1
address family: AF_INET loopback
framing: uint32 big-endian byte length + canonical UTF-8 JSON
maximum frame: 1,048,576 bytes
serialization: mandatory on measured path
```

Direct object queues, shared-memory object calls, or in-process callbacks are not rankable substitutes for the frozen transport.

Each reference message carries:

```text
schema
message_id
message_kind
sender_role
receiver_role
subject_type
subject_id
payload_schema
payload
send_monotonic_ns
```

`message_id` is a transport/idempotence identity, never semantic authority. The receive side validates frame size, schema, required fields, and payload type before semantic dispatch.

Transport de-duplication may reduce work, but safety must still derive from Continuity semantic identity and commit guards. The same semantic completion under different transport IDs must remain safe.

## 4. Clock contract

C8 uses `time.monotonic_ns` for local duration measurement only. Clocks may measure decision, reconciliation, transport, recovery, and benchmark durations. They may not determine Attempt authority, Binding currency, State compatibility, Evidence sufficiency, or ownership commitment. No synchronized wall clock is required for safety.

## 5. Cross-layer replay contract

For correctness-equivalent traces:

```text
C1 authoritative semantic outcome
== C2 authoritative semantic outcome
== C8 authoritative semantic outcome
```

Timing and physical event ordering may differ.

Frozen trace families:

| Trace | Prior/reference path | C8 real-process injection | Required semantic outcome |
| --- | --- | --- | --- |
| `C8-X1-LATE-SUPERSEDED-ATTEMPT` | `attempt_fencing_e1.py` + replay/fault campaign | delay old completion past newer Attempt | superseded Attempt cannot finalize |
| `C8-X2-DUPLICATE-COMPLETION` | `idempotence_ordering_e1.py` | duplicate serialized completion frame | no duplicate authoritative finalization |
| `C8-X3-WRONG-SIBLING-STATE` | `state_lineage_e1.py` | expose attractive incompatible sibling State | incompatible State rejected |
| `C8-X4-STALE-BINDING` | `binding_safety_e1.py` | deliver older Binding epoch after replacement | stale Binding cannot regain authority |
| `C8-X5-AMBIGUOUS-OWNERSHIP` | `evidence_safety_e1.py` | deliver conflicting insufficient ownership observations | correctness-sensitive commit fails closed |
| `C8-X6-STATE-EVICTION-TOOL-WAIT` | core replay + simulator eviction; no direct C4 EV1 | evict sole physical State while suspended | resume recomputes/rejects/fails, never consumes absent/incompatible State |
| `C8-X7-PARTIAL-MIGRATION` | Binding/Evidence replay + migration/fault machinery | interrupt materialization before migration commit | partial materialization cannot authorize ownership transfer |

C7 retention and migration efficiency evidence remains separate and is not relabeled as C8 correctness evidence.

## 9. Measurement procedure

Headline Gate G3 timing uses:

```text
warm-up operations       200
samples/repetition       1,000
repetitions              7
bootstrap resamples      10,000
bootstrap seed           8,012,026
interval                 paired repetition-level 95% percentile bootstrap
latency summaries        median, p95, p99
outlier handling         NO_SILENT_TRIMMING
non-finite handling      INVALID_RESULT
```

Paired measurements use the same initial conditions. Repetition captures physical timing variation; deterministic semantic traces are not treated as independent semantic replications.

`PRODUCTION_GUARDS_PLUS_DEBUG` timing is diagnostic only. Headline timing uses `PRODUCTION_GUARDS_ONLY` so debug-only whole-graph scans are not mistaken for mandatory production overhead.

## 12. Gate G3 rule

C8.1 freezes **no universal percentage threshold**.

Gate G3 asks whether Continuity becomes a dominant serving bottleneck over a declared intended workload region. The answer must use absolute measured CPU/control-plane cost, scaling behavior, and evidence-separated comparisons with relevant inference-operation timing. A favorable narrow cell is not a universal practicality claim; negative or bounded results are valid outcomes.

## 13. C8.2 conformance requirements

Before C8.2 measurements can be EV1 evidence, the implementation must prove:

1. authority, worker, and fault-harness roles occupy declared distinct OS PIDs;
2. rankable messages cross real loopback TCP;
3. canonical serialization is exercised on the measured path;
4. worker termination/restart uses real process lifecycle;
5. fault injection is external to semantic authority;
6. only the authority commits Continuity mutations;
7. timestamps do not authorize semantics; and
8. deterministic semantic logs can be reconciled with the frozen C1/C2 trace mapping.
