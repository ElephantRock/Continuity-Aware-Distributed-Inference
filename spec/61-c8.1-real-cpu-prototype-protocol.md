## 1. Purpose

C8 moves CADI from deterministic and simulated execution to real CPU distributed execution. C8.1 freezes the scientific and implementation boundary before the C8.2 prototype or any headline practicality measurement exists.

The protocol has two jobs:

1. preserve the already-closed Continuity semantics under real process/IPC concurrency; and
2. make later Gate G3 measurements reproducible, evidence-labeled, and resistant to post-result protocol changes.

C8.1 does **not** measure the final prototype and does not adjudicate Gate G3.

---

The existing Continuity Core remains authoritative. C8 may distribute physical execution and observation, but it may not distribute semantic authority without a separately reviewed change to Paper 1 assumptions.

Frozen semantic dependencies include:


The canonical K1–K5 obligations remain unchanged:

## 3. Process roles and trust

The reference prototype has exactly these semantic roles:

```text
CONTROL_PLANE_AUTHORITY
WORKER
FAULT_TRANSPORT_HARNESS
```

### CONTROL_PLANE_AUTHORITY

The only process role permitted to commit authoritative Continuity mutations. It owns the in-process `ContinuityCore` instance used for correctness-sensitive transitions.

### WORKER

Executes physical work and emits serialized observations/completions. A worker may become delayed, duplicated, restarted, or terminated. Worker-local state does not confer semantic authority.

### FAULT_TRANSPORT_HARNESS

Controls delivery behavior outside the semantic authority. It may delay, duplicate, reorder, or fail delivery where a declared scenario permits. It may not forge semantic identities or directly mutate Continuity state.

A separate State-service process is not part of C8.1. C8.2 may add one only if the required State-loss/migration traces cannot be represented faithfully without an independently failing State process. Adding such a role requires an explicit protocol revision before its measurements are rankable.

## 4. Reference transport

The reference transport is frozen as:

```text
LOOPBACK_TCP_LENGTH_PREFIXED_CANONICAL_JSON_V1
```

Properties:

```text
address family    AF_INET loopback
OS boundary       real process + kernel socket boundary
framing           uint32 big-endian byte length + payload
payload           canonical UTF-8 JSON
max payload       1,048,576 bytes
serialization     mandatory on measured path
```

The canonical JSON representation uses sorted keys, compact separators, and rejects non-finite values.

The transport must not be replaced by a direct Python object queue, shared-memory object call, or in-process callback for a rankable Gate G3 result. Such mechanisms may be diagnostic implementations but are not the frozen reference path.

## 5. Message envelope

Every cross-process reference message carries:

```text
schema
message_id
message_kind
sender_role
receiver_role
subject_type
subject_id
payload_schema
payload
send_monotonic_ns
```

`message_id` is a transport/idempotence identity. It is **not** a new Continuity semantic identity and cannot authorize a correctness-sensitive transition.

`subject_type` / `subject_id` refer to already-defined semantic subjects such as an Attempt, State, Binding subject, LogicalRequest, or Continuation. The envelope must not create an alternative hidden identity hierarchy.

The receive-side prototype must validate schema, frame size, required fields, and payload type before semantic dispatch.

---

## 6. Duplicate and idempotence rule

Transport duplication is expected and must be survivable.

A repeated `message_id` may be detected for transport accounting, but correctness still derives from Continuity semantic identity and commit guards. Therefore:

```text
transport de-duplication may reduce work
but
transport de-duplication is not the safety proof
```

If the same semantic completion is delivered under two different transport message IDs, the Continuity layer must still preserve idempotence/fencing.

## 7. Clock contract

C8 uses:

```text
time.monotonic_ns
```

for local duration measurement.

Clocks may measure:

```text
send-to-receive latency
decision latency
reconciliation latency
failure recovery latency
benchmark intervals
```

Clocks may **not** decide:

```text
which Attempt is authoritative
which Binding epoch is current
whether State lineage is compatible
whether Evidence is sufficient
whether an ambiguous ownership observation may commit
```

C8 requires no synchronized wall clock for safety.

## 8. Cross-layer replay contract

C8 freezes seven trace families. For correctness-equivalent traces:

```text
C1 semantic outcome == C2 semantic outcome == C8 semantic outcome
```

Physical timestamps, queue residence, process scheduling, and measured latency need not match.

### C8-X1 — late superseded Attempt

References:

```text
C1: tests/counterexamples/test_failure_model_traces.py + continuity/replay.py
C2: simulator/faults.py + simulator/fault_campaign.py
prior EV1: experiments/attempt_fencing_e1.py
```

C8 injection: delay an older real worker completion until a newer Attempt is current.

Required semantic outcome:

```text
superseded Attempt cannot finalize the LogicalRequest
```

Forbidden metric: nonzero Stale Attempt Acceptance Rate.

### C8-X2 — duplicate completion

References:

```text
C1: failure-model trace / operation replay
C2: fault duplication schedule
prior EV1: experiments/idempotence_ordering_e1.py
```

C8 injection: duplicate a real serialized worker-completion frame.

Required semantic outcome:

```text
duplicate completion cannot produce duplicate authoritative finalization
```

Forbidden metric: nonzero Duplicate Finalization Rate.

### C8-X3 — wrong sibling State

References:

```text
C1: State-lineage counterexample/replay
C2: State/fault + semantic adapter
prior EV1: experiments/state_lineage_e1.py
```

C8 injection: expose physically attractive State from an incompatible sibling Continuation.

Required semantic outcome:

```text
incompatible sibling State is rejected for consumption
```

Safe outcomes include recompute, reject, or explicit failure.

### C8-X4 — stale Binding

References:

```text
C1: Binding counterexample/replay
C2: stale event through fault/semantic-adapter path
prior EV1: experiments/binding_safety_e1.py
```

C8 injection: deliver an older Binding-epoch observation after replacement.

Required semantic outcome:

```text
stale Binding cannot regain authoritative ownership
```

Forbidden metric: nonzero Silent Binding Divergence Rate.

### C8-X5 — ambiguous ownership

References:

```text
C1: Evidence/ambiguity replay
C2: fault oracle + Evidence scheduling
prior EV1: experiments/evidence_safety_e1.py
```

C8 injection: deliver conflicting, individually insufficient ownership observations.

Required semantic outcome:

```text
correctness-sensitive ownership commit fails closed
```

`AMBIGUOUS`, wait, retry, recompute, or fail may be safe depending on the operation.

### C8-X6 — State eviction during tool wait

References:

```text
C1: continuity/replay.py + State invariant tests
C2: State eviction fault schedule
prior direct C4 EV1: none
```

C7 retention evidence remains a separate efficiency result and must not be relabeled as C8 correctness evidence.

C8 injection: evict the only physical replica while the Continuation is suspended.

Required semantic outcome:

```text
resume recomputes/rejects/fails rather than consuming absent or incompatible State
```

### C8-X7 — partial migration

References:

```text
C1: Binding/Evidence invariant replay
C2: migration interruption + fault oracle
prior EV1: Binding/Evidence safety modules
```

C8 injection: interrupt destination materialization before authoritative migration commit.

Required semantic outcome:

```text
partial materialization cannot authorize ownership transfer without sufficient Evidence
```

## 13. Measurement procedure

Headline rankable timing uses:

```text
warm-up operations           200
samples per repetition       1,000
repetitions                  7
bootstrap resamples          10,000
bootstrap seed               8,012,026
interval                     paired repetition-level 95% percentile bootstrap
latency summaries            median, p95, p99
```

Policy:

```text
non-finite value      INVALID_RESULT
outlier handling      NO_SILENT_TRIMMING
host load metadata    required
debug timing          diagnostic only if debug-only graph scans are enabled
```

The same initial State/resource conditions must be used for paired measurements. Stochastic faults use an explicit seed. Deterministic traces do not gain artificial statistical significance from repeated semantic outcomes; repetition is for physical timing variability only.

## 14. Debug and measurement perturbation

Required production correctness guards remain enabled in all rankable runs.

Expensive debug-only invariant scans may be used for diagnostics. If enabled, that run is classified:

```text
PRODUCTION_GUARDS_PLUS_DEBUG
```

and is not a headline Gate G3 timing result under this protocol.

Rankable headline timing uses:

```text
PRODUCTION_GUARDS_ONLY
```

This distinction prevents test instrumentation from being mistaken for unavoidable control-plane overhead.

## 17. Gate G3 rule

C8.1 deliberately freezes **no universal percentage threshold**.

Gate G3 asks:

> Does Continuity become a dominant serving bottleneck over a declared intended workload region?

The answer must be based on absolute measured CPU/control-plane costs, scaling response, and explicitly labeled comparison with relevant inference-operation times.

A favorable answer in one narrow cell is insufficient for a universal practicality claim. A negative or bounded result remains scientifically valid.

---

## 18. C8.2 implementation constraints

The next slice may implement the frozen design, but before its measurements become evidence it must prove:

1. at least one worker is a distinct OS process from the authority;
2. rankable messages cross the real loopback TCP transport;
3. the canonical serializer is actually exercised;
4. worker termination/restart is real process lifecycle behavior;
5. fault injection occurs outside semantic authority;
6. only the authority process commits Continuity mutations;
7. message timestamps are ignored by semantic authorization;
8. deterministic semantic event logs can be reconciled with C1/C2 traces.

C8.2 may not replace these with in-memory simulation while retaining the EV1 label.

## 20. C8.1 exit condition

C8.1 closes only after:

- protocol code/spec/tests are exact-head green;
- the fingerprint is literally frozen;
- existing Continuity/simulator semantic parents are unchanged from the declared base;
- C7 result provenance remains intact;
- bounded technical/scientific review finds no blocker; and
- `headline_c8_measurement_inspection = NONE` remains true.

Only then may C8.2 begin the real distributed substrate implementation.
