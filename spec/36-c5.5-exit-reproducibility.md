## Reproducibility harness

`experiments/c5_exit.py` accepts only bytes matching the pinned Mooncake SHA-256. It performs two independent end-to-end constructions and compares canonical JSON for all six artifacts:

```text
normalized source dataset
SOURCE_DERIVED envelope
Continuity augmentation dataset
TRACE_AUGMENTED envelope
fully synthetic workload dataset
FULLY_SYNTHETIC envelope
```

The harness fails closed on raw-source checksum drift, normalized source fingerprint drift, request-count drift, source-envelope fingerprint drift, augmentation fingerprint/count drift, trace-envelope fingerprint drift, synthetic dataset/envelope fingerprint drift, augmentation source-binding drift, provenance drift, mode ambiguity, failed artifact matching, source mutation, or any replay mismatch.

It emits one canonical compact JSON summary containing the source checksum/fingerprint, all envelope fingerprints, augmentation fingerprint and counts, source field-origin map, provenance labels, explicit mode list, and replay result.

## Evidence layers

Two distinct validation layers are retained:

1. `tests/experiments/test_c5_exit.py` uses a bounded fixture with explicit monkeypatched source authority only to validate harness mechanics, deterministic replay, mode distinction, artifact-match calls, count consistency, source immutability, frozen-vector fail-closed behavior, and fail-before-construction behavior for non-pinned bytes.
2. `.github/workflows/c5-exit.yml` downloads and validates the actual pinned Mooncake public source and is the EV2 source evidence for C5 exit.

Fixture tests are not promoted as public-trace evidence.

## C5 exit criterion

C5 may close only if the final exact-head source-backed run and bounded technical/scientific review jointly establish:

```text
real/source-derived workload constructible + distinguishable
trace-augmented workload constructible + distinguishable
fully synthetic workload constructible + distinguishable
source/derived/synthetic provenance retained end-to-end
deterministic replay/fingerprints demonstrated
all tests/CI green
no physical-performance claim promoted beyond EV2
```

The establishment run `34134973651` is not the exit run. After freezing the exact vector, a new source-backed workflow run on the final candidate head must reproduce every value byte-for-byte/fingerprint-for-fingerprint. Only that final run may support C5 closure.
