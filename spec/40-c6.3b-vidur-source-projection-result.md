## Frozen source-row aggregation

The dedicated C6.3b source-structure probe established that the selected Vidur artifacts contain multiple non-identical profiling observations for some logical source points. The projection rule was frozen before the full fit result was inspected:

```text
1. apply the exact C6.3a domain filter;
2. collapse byte-identical/exact duplicate physical rows;
3. retain distinct source observations at the same logical axis value;
4. compute each physical row's declared median-based component composition;
5. aggregate retained observations by equal-weight arithmetic mean;
6. use stable summation for deterministic arithmetic;
7. emit one deterministic reference point per logical axis value.
```

This rule is source-semantic normalization only. It does not perform outlier rejection, residual-based filtering, cherry-picking, or validation-aware weighting.

## Frozen fit law

For each `(hardware_id, reference_kind)` family, C6.3b fits only C6.3a `FIT` points using deterministic ordinary least squares:

```text
y = intercept + slope * x
```

with stable summation.

Admissibility is fail-closed:

```text
coefficients finite
slope > 0
intercept >= 0
```

The transfer mapping, when admissible, is:

```text
transfer_latency_seconds = intercept
transfer_bandwidth_bytes_per_second = 1 / slope
```

A family violating the admissibility rule is retained as an invalid scientific result. It is not clipped, constrained, refitted over a narrower domain, or repaired by source-row removal.
