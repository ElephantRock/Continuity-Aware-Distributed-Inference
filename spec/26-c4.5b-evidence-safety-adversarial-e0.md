# C4.5b — Adversarial S4 Evidence Safety EV0

Issue: #76

## Purpose

C4.5b extends the repaired deterministic C4.5a Evidence-safety result into an adversarial EV0 corpus without changing C1/C2/C3 semantics before measurement.

The primary semantic action remains request finalization. Ground truth is declared independently of policy execution, and reconciliation is recorded separately from authoritative semantic commit.

## Adversarial dimensions

The bounded manifest covers:

- contradictory same-scope VALID exact Evidence;
- agreeing multi-Evidence positive control;
- supplied AMBIGUOUS Evidence mixed with sufficient Evidence;
- `valid_until` equality and immediate-expiry boundaries;
- old `observed_at` without expiry or an action-defined max-age;
- AUTHORITATIVE authority above the finalize minimum;
- DERIVED Evidence with exact support but no authority smuggling into the Output;
- sufficient Evidence plus unrelated VALID scope;
- wrong-scope-only Evidence;
- empty Evidence sets.

Six cases are faulted and each carries one fixed exogenous paired ACR EventID. Five cases are non-faulted positive controls.

## Independent contradiction oracle

The controlled contradiction fixture supplies two VALID `EXACT_OBSERVATION` Evidence objects over the same Attempt scope and the same terminal-outcome fact:

```text
attempt-terminal-outcome=SUCCEEDED
attempt-terminal-outcome=FAILED
```

These claims are mutually exclusive by fixture construction. The independent oracle therefore requires:

```text
oracle reconciliation = AMBIGUOUS
semantic commit allowed = false
```

The harness does **not** require observed C1 reconciliation to equal this oracle before classification. Any observed `MATCHED` plus authoritative commit is measured as ACR/O4 rather than hidden behind a pre-classification assertion.

## Freshness boundary

C1 currently defines expiration using `valid_until` and optional consumer `max_age`. Request finalization does not provide an action-specific `max_age`, so an old `observed_at` alone is intentionally a positive control rather than being silently reinterpreted as stale.

`valid_until == now` is valid under the current comparison (`now > valid_until` means expired). `valid_until < now` must fail closed.

## Provenance and set-integrity guards

In addition to the paired finalization corpus, direct adversarial tests require:

- VALID DERIVED Evidence cannot be built from non-VALID support;
- non-DERIVED Evidence cannot carry derivation provenance;
- conflicting duplicate Evidence identity is rejected;
- Outputs cannot reference unknown Evidence IDs;
- state consumption does not union state and replica scope across separate insufficient Evidence items;
- migration commit does not union Binding and epoch scope across separate insufficient Evidence items.

These checks validate C1 ingestion/requirement integrity and do not create policy-level comparator claims.

## Baseline contract

B0–B4 retain the common C1 finalization authority. Only B4 receives the frozen Evidence authority/status/freshness/reconciliation policy fields already permitted by C3. No baseline bypasses the shared semantic guard.

## Metrics

Primary paired metrics:

```text
ACR  Ambiguous Commit Rate
SSER Silent Semantic Error Rate
```

Faulted denominators are exogenous and fixed before policy execution. Positive controls have no fault denominator.

The expected pre-measurement safety requirement is zero ACR/O4 for all competent policies. If the adversarial corpus reveals a common C1 defect, this branch is preserved as pre-repair evidence and must not be merged as a successful C4.5b closure.

## Measurement provenance

Every paired trial records:

```text
ground truth / oracle reconciliation
raw Evidence objects
observed C1 reconciliation
policy-visible Evidence projection
C1 finalization result
Request/Attempt authority after the operation
operation-level semantic result
```

A private divergence injection remains available to prove that the metric path can report ACR/O4 after an ordinary C1 rejection.

## Exit rule

C4.5b may close only after exact-head Python 3.11/3.12/3.13 CI and bounded review. Any real semantic defect discovered here requires an explicit repair gate, independent repair merge, and post-repair reproduction before C4.5c EV1 begins.
