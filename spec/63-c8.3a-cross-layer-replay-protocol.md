## Scientific boundary

C8.3a defines how C1 deterministic semantics, C2 deterministic simulator/fault semantics, and C8 real-process CPU executions will be compared in C8.3b. It does not execute the seven campaigns and does not inspect their aggregate outcomes.

No latency, throughput, CPU, memory, scalability, or Gate G3 practicality result is generated here. Timing is not a semantic comparison input.

## Why equivalence is checkpoint-based

A trace is not reduced to one final scalar result. Several frozen traces contain more than one correctness-sensitive semantic moment. For example:

- `C8-X1-LATE-SUPERSEDED-ATTEMPT` first requires the current Attempt to commit and then requires a late superseded Attempt to be rejected;
- `C8-X2-DUPLICATE-COMPLETION` first requires one authoritative finalization and then requires the duplicate presentation to be idempotent.

Therefore C8.3 equivalence is defined over an ordered vector of semantic checkpoints. A correct final state may not hide an incorrect intermediate authoritative action.

Canonical comparison row order is:

```text
C1 checkpoints in declared order
C2 checkpoints in declared order
C8 checkpoints in declared order
```

Missing, duplicate, or reordered rows are invalid.

## Normalized outcome vocabulary

The frozen normalized vocabulary is:

```text
COMMITTED
REJECTED
WAIT
RETRY
RECOMPUTE
FAIL
AMBIGUOUS
IDEMPOTENT_NOOP
```

Layer-specific raw observations are frozen before campaign execution. Each checkpoint carries explicit raw-to-normalized rules for C1, C2, and C8.

A result row may represent:

1. the expected safe outcome;
2. a predeclared semantic checkpoint failure;
3. for a correctness-metric opportunity, a predeclared forbidden semantic outcome;
4. for C8 only, an explicit replay-execution failure.

This is deliberate. A forbidden result must remain representable as scientific evidence. The validator must not reject a real semantic violation merely because it differs from the expected result.

Post-result invention of a new raw-outcome classification is forbidden.

## Equivalence is not correctness

C8.3a freezes four distinct predicates:

```text
semantic_equivalent
expected_outcomes_satisfied
forbidden_violation_free
rankable
```

`semantic_equivalent` asks whether C1, C2, and C8 produced the same normalized checkpoint vector and the same canonical semantic-state fingerprints.

It does **not** require that the common behavior is correct.

Therefore this case is valid and must remain expressible:

```text
C1 = forbidden behavior
C2 = forbidden behavior
C8 = forbidden behavior
semantic_equivalent = true
correctness_pass = false
```

This avoids conflating cross-layer agreement with correctness.

`correctness_pass` is derived only when all of the following hold:

- replay is rankable;
- C1/C2/C8 are semantically equivalent;
- every layer matches the expected checkpoint vector;
- all forbidden-metric violation counts are zero.

No caller may directly choose these derived booleans.

## Semantic-state projection evidence

Every checkpoint freezes a non-empty `semantic_projection_fields` list. C8.3b must build a canonical JSON projection from those authoritative fields and store:

```text
SHA-256(canonical semantic projection)
```

as `semantic_state_fingerprint`.

The projection is intentionally semantic rather than implementation-wide. It excludes physical queue order, local event index, timestamps, host scheduling, and other non-authoritative details.

Cross-layer semantic equivalence requires both:

1. identical normalized checkpoint vectors; and
2. identical semantic-state fingerprint vectors.

This prevents equal labels from hiding different authoritative state.

## Execution provenance

Every C1/C2/C8 row carries one `execution_git_commit`. A comparison is invalid if rows in the same trial were produced from different Git commits.

The C8.3b executor must derive this SHA from its clean running checkout. C8.3a validates the SHA shape; C8.3b remains responsible for rejecting tracked or non-ignored untracked checkout drift before generating evidence.

## C8 topology and transport provenance

Each C8 row must carry exactly:

```text
authority_pid
authority_port
fault_harness_pid
worker_port
worker_pids
transport_id
real_process_boundary
```

Requirements:

- authority, harness, and all worker-generation PIDs are positive and mutually distinct;
- worker PID cardinality equals the frozen number of worker generations for the trace;
- authority and worker listen ports are valid and distinct;
- `transport_id` is the frozen C8.1/C8.2 reference transport;
- `real_process_boundary = true`.

C8.3b must source these values from the actual process/event logs. Caller-supplied fake topology is not evidence.

Every C8 row also carries a trace-specific fault/lifecycle-script fingerprint. C1/C2 rows may not carry C8 topology or fault-script provenance.

## Replay-execution failure

The reserved raw outcome:

```text
REPLAY_EXECUTION_FAILURE
```

is available only for the physical C8 layer. It normalizes to `FAIL`, is explicit non-success, and makes the comparison unrankable.

An intended fault in the trace—such as deliberate worker termination in X6 or X7—is not itself a replay-execution failure. A replay-execution failure means the declared experiment could not be completed according to the frozen contract.

A replay-execution failure does not silently create a forbidden semantic violation. It is reported separately through `execution_failure_count`.

## Opportunity and violation semantics

Opportunity denominators are checkpoint-level and frozen before execution.

For each opportunity checkpoint:

```text
opportunities = 1
```

For non-opportunity checkpoints:

```text
opportunities = 0
```

The validator rejects denominator changes.

Each opportunity also freezes a forbidden raw semantic classification for every layer. When that classification is observed:

```text
violations = 1
```

otherwise:

```text
violations = 0
```

This preserves the previously established C4 metric numerator/opportunity meaning and prevents post-result denominator repair.

## Trace contracts

### X1 — late superseded Attempt

Metric: `Stale Attempt Acceptance Rate`.

Checkpoints:

```text
current-attempt-finalize -> COMMITTED
stale-attempt-presentation -> REJECTED [opportunity]
```

C8 uses two worker generations. Generation-1 completion is captured and held, generation 1 is terminated, generation 2 becomes current and completes, and the old completion is then late-delivered through the external harness.

Forbidden classification: `STALE_ATTEMPT_COMMITTED`.

Semantic projection includes the committed Attempt, authoritative output, and stale Attempt authority status.

### X2 — duplicate completion

Metric: `Duplicate Finalization Rate`.

Checkpoints:

```text
first-finalization -> COMMITTED
duplicate-presentation -> IDEMPOTENT_NOOP [opportunity]
```

The external harness applies deterministic `DUPLICATE` to the worker `COMPLETE` frame.

Forbidden classification: `DUPLICATE_FINALIZATION`.

Semantic projection includes authoritative output, Attempt authority status, and finalization count.

### X3 — wrong sibling State

Metric: `Wrong-Branch Reuse Rate`.

Checkpoint:

```text
incompatible-state-consume -> REJECTED [opportunity]
```

The authority constructs sibling Continuations and the physical worker path triggers an authority-local consume decision against State from the incompatible sibling.

Forbidden classification: `WRONG_SIBLING_STATE_CONSUMED`.

Semantic projection includes State origin Continuation, target Continuation, compatibility, and consumption disposition.

### X4 — stale Binding

Metric: `Silent Binding Divergence Rate`.

Checkpoints:

```text
replacement-binding-commit -> COMMITTED
stale-binding-presentation -> IDEMPOTENT_NOOP [opportunity]
```

The old-owner observation is delayed through the external harness until after the replacement Binding is authoritative.

Forbidden classification: `STALE_BINDING_RESTORED`.

Semantic projection includes current Binding identity, current epoch, and old Binding status.

### X5 — ambiguous ownership

Metric: `Ambiguous Commit Rate`.

Checkpoint:

```text
ambiguous-reconciliation -> AMBIGUOUS [opportunity]
```

Physical observation enters through C8, while Evidence construction/reconciliation remains authority-local.

Forbidden classification: `AMBIGUOUS_OWNERSHIP_COMMITTED`.

Semantic projection includes current Binding, candidate status, and reconciliation outcome.

### X6 — State eviction during tool wait

Metric: `Wrong-State Consumption Rate`.

Checkpoint:

```text
resume-after-eviction -> REJECTED [opportunity]
```

The Continuation is suspended, the worker containing the sole physical replica is deliberately terminated, replica loss is observed, and resume attempts reuse.

Forbidden classification: `LOST_REPLICA_CONSUMED`.

Semantic projection includes State lineage, replica status, Continuation lifecycle, and consume disposition.

### X7 — partial migration

Metric: `Ambiguous Commit Rate`.

Checkpoint:

```text
partial-migration-commit -> WAIT [opportunity]
```

The authority begins migration, destination materialization begins, the destination worker is deliberately terminated before authoritative commit, and commit is attempted without sufficient Evidence.

Forbidden classification: `PARTIAL_DESTINATION_COMMITTED`.

Semantic projection includes current Binding, candidate Binding status, current epoch, and destination materialization state.

## Invalid / unrankable conditions

Invalid:

- C8.1 trace IDs or forbidden metrics drift;
- protocol fingerprint drift;
- unknown/post-hoc raw normalization;
- omitted or modified opportunity denominator;
- missing/duplicate/noncanonical layer-checkpoint rows;
- inconsistent execution Git SHA;
- malformed semantic-state digest;
- C8 topology or fault-script provenance mismatch;
- C8 transport identity drift;
- C8 topology with duplicate/fake-shaped PIDs or invalid ports;
- C1/C2 row carrying C8-only provenance;
- timing used to derive semantic equivalence.

Unrankable:

- explicit physical C8 replay-execution failure.

Scientific semantic failures are not invalid. They remain valid rows and can make the comparison fail.
