# C4.5c — Measured Distributed S4 Evidence Safety EV1

Issue: #81  
Parent: #69  
Base: `5dc4032d1f8fd726fab429dfff2416e0d931c740`

## Purpose

C4.5c is the measured distributed validation slice for H3/S4. It asks whether the repaired common C1 Evidence/reconciliation mechanism continues to fail closed when observations originate in real independent CPU processes and cross an IPC boundary before becoming Evidence.

This is the final mandatory C4.5 Evidence-safety rung. It follows two EV0 defect→repair→reproduction sequences and does not erase either historical failure.

## Historical provenance

C4.5a deterministic EV0 first exposed that a mixed `VALID + AMBIGUOUS` Evidence set could reconcile `AMBIGUOUS` while direct semantic Evidence requirement ignored the ambiguous item and finalized. Preserved PR #71 measured ACR `1/9`, then repair #72/#73 was independently merged and PR #75 reproduced ACR `0/9`.

C4.5b adversarial EV0 then exposed that two individually `VALID` exact observations asserting mutually exclusive values for the same semantic fact could be silently collapsed to success because C1 lacked machine-readable semantic claim identity/value. Preserved PR #77 measured ACR `1/6`; repair #78/#79 introduced structured `claim_key` / `claim_value`; post-repair PR #80 reproduced ACR `0/6` and merged as `5dc4032d1f8fd726fab429dfff2416e0d931c740`.

C4.5c measures the repaired mechanism rather than assuming those EV0 results generalize to a real process/IPC boundary.

## Runtime measurement boundary

The harness uses:

```text
multiprocessing start method = spawn
workers                      = w1, w2, w3
IPC                           = multiprocessing.Pipe
minimum measured CPU/event    = 0.004 process seconds
```

Each worker has a distinct operating-system PID. Observation and controlled-crash events execute deterministic SHA-256 CPU work and record:

```text
worker_id
worker_pid
started_at
observed_at / completed_at
delivered_at
process_cpu_seconds
wall_execution_seconds
cpu_digest
```

The coordinator verifies message type, worker identity, and PID. Workers cannot mutate C1. Only the coordinator converts delivered measurements into `Evidence` and invokes the common semantic authority.

Validation level is `EV1_MEASURED_CPU_DISTRIBUTED`; result Evidence provenance is `MEASURED`.

## Predeclared scenarios

The canonical set was fixed in issue #81 before implementation:

```text
E1-S4-A-CONTRADICTORY-WORKERS
  w1 => VALID EXACT attempt:a1:terminal-outcome = SUCCEEDED
  w2 => VALID EXACT attempt:a1:terminal-outcome = FAILED
  oracle AMBIGUOUS; commit forbidden
  EventID S4:EV1:A:contradictory-workers-finalization

E1-S4-B-EXPLICIT-AMBIGUOUS-WORKER
  real worker => AMBIGUOUS EXACT current-Attempt observation
  oracle AMBIGUOUS; commit forbidden
  EventID S4:EV1:B:ambiguous-worker-finalization

E1-S4-C-EXPIRED-MEASURED-OBSERVATION
  real worker => VALID EXACT current-Attempt observation
  valid_until is explicitly earlier than its measured observation/commit time
  oracle WAIT; commit forbidden
  EventID S4:EV1:C:expired-worker-finalization

E1-S4-D-WORKER-CRASH-NO-EVIDENCE
  w2 executes measured CPU work and exits with controlled non-zero code
  before any usable Evidence observation is delivered
  oracle WAIT; commit forbidden
  EventID S4:EV1:D:worker-crash-finalization

E1-S4-E-WRONG-SCOPE-WORKER
  real worker => VALID EXACT Evidence for another Attempt
  oracle WAIT; commit forbidden
  EventID S4:EV1:E:wrong-scope-worker-finalization

E1-S4-F-AGREEING-WORKERS-CONTROL
  w1 and w2 independently assert the same structured SUCCEEDED value
  oracle MATCHED; commit allowed

E1-S4-G-SINGLE-VALID-WORKER-CONTROL
  one real worker supplies sufficient VALID EXACT current-Attempt Evidence
  oracle MATCHED; commit allowed
```

There are five faulted cases and two positive controls. Fault opportunities have fixed exogenous paired ACR EventIDs independent of policy execution.

## Paired measurement rule

Each physical scenario is measured once, then the same delivered worker events are replayed into separate B0–B4 semantic evaluations. This avoids confounding baseline comparison with different process schedules or timestamps.

Ground truth contains no measured random timestamps/PIDs and is policy invariant. Physical events live only in observed Evidence/provenance.

## Evidence construction

For delivered worker observations, coordinator-side Evidence is:

```text
authority   = EXACT_OBSERVATION
status      = worker-declared VALID or AMBIGUOUS
observed_at = measured worker timestamp
scope       = Attempt + worker ID + worker PID
source      = C4.5c real worker process
```

Structured semantic fields are explicit:

```text
claim_key   = attempt:<scope-attempt>:terminal-outcome
claim_value = SUCCEEDED | FAILED | UNKNOWN
```

The human-readable `claim` is diagnostic only and is not parsed to infer contradiction.

The crash case deliberately creates no Evidence object. The expired case derives `valid_until` from the measured observation timestamp but sets it strictly earlier than that observation, guaranteeing expiry without wall-clock sleep/flakiness.

## Semantic authority and baseline fairness

All B0–B4 use the same C1 finalization authority. No baseline bypasses `require_evidence` or reconciliation safety.

The existing C3 information contract is preserved:

```text
B0-B3: no Evidence/reconciliation policy fields
B4:    Evidence authority/status/freshness + reconciliation fields
```

Those policy-visible fields are diagnostic here; C1 remains authoritative for semantic commit. If all policies are equally correct, C4.5c records a semantic null comparator rather than inventing a B4 correctness advantage.

## Measurement record

Each trial records independently:

```text
oracle ground truth
fixed EventID / fault class
three worker PIDs
physical worker events
measured Evidence objects
semantic commit time
observed reconciliation
oracle reconciliation and divergence flag
policy-visible projection
finalization presentation
Request/Attempt post-state
operation-level semantic result
```

The harness does not assert observed reconciliation equals the oracle before semantic classification. An unexpected authoritative commit remains measurable as ACR/O4.

A private anti-false-zero path forces authority only after a real C1 rejection and must still produce ACR/O4, demonstrating metric sensitivity.

Both positive controls must finalize successfully. Contradictory/ambiguous cases should explicitly reject with `AMBIGUOUS`; expired/crash/wrong-scope cases should explicitly reject after `WAIT`.

## H3/S4 decision boundary

C4.5c alone does not rewrite the earlier defects. Final H3/S4 adjudication must consider the complete record:

```text
C4.5a: defect found -> explicit repair -> deterministic reproduction passes
C4.5b: second defect found -> explicit representation/repair -> adversarial reproduction passes
C4.5c: measured distributed validation of the repaired mechanism
```

If C4.5c is clean, the supported claim is scoped to a required **common semantic Evidence-safety mechanism after explicit repairs**. Because B0–B4 retain common C1 authority, this correctness slice does not establish a unique B4 semantic comparator win.
