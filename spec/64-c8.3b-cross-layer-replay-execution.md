## Real-process replay architecture

The C8 authority process is the only process that owns and mutates `ContinuityCore`. Stock C8.2 workers remain semantic-authority-free. A dedicated C8.3 external replay harness reuses the frozen C8.2 wire contract, frame codec, loopback transport, roles, and `DeliveryScheduler` but exposes explicit transport-only release controls to the parent experiment orchestrator.

This controlled release is required to realize frozen C8.3a lifecycle ordering without changing the protocol:

- X1 holds generation-1 `COMPLETE`, starts generation 2 after the generation-1 process failure is observed, commits generation 2, then releases the old completion late.
- X4 holds the stale completion/observation until the replacement Binding is committed, then releases the stale transport frame.

The parent orchestrator owns no semantic state and cannot mutate `ContinuityCore`.

## Projection identity

`semantic_projection_fields` freezes field identity and the order used to construct scientific projection fingerprints. Canonical JSON object serialization sorts keys; therefore raw mapping iteration order is not evidence. The executor:

- rejects missing, extra, or duplicated projection fields;
- reconstructs the projection in the frozen tuple order before hashing;
- compares the resulting fingerprints across C1, C2, and C8.

## Physical replay failure

If C8 establishes valid frozen topology provenance but cannot complete the semantic replay, each C8 checkpoint is emitted with:

- `raw_outcome = REPLAY_EXECUTION_FAILURE`;
- normalized outcome `FAIL`;
- frozen opportunity denominator preserved;
- zero semantic violations attributed to the failed physical replay;
- `replay_execution_failure = true`;
- valid C8 topology and fault-script provenance.

The trace is unrankable. A failure before complete topology provenance is an invalid campaign and aborts artifact generation rather than manufacturing evidence.

## Reproducibility

Raw C8 artifacts intentionally retain OS PIDs and kernel-assigned listen ports. Independent physical executions therefore are not required to have identical artifact bytes.

The execution gate requires:

1. canonical serialization of each individual result to be byte-identical when rewritten;
2. two independent full seven-trace executions to have exactly identical topology-normalized scientific payload/fingerprint and summary;
3. both raw artifacts to retain their actual physical topology provenance.

## Result contract

Schema: `cadi.c8.3b.cross-layer-replay-result.v1`.

The canonical result contains:

- exact execution Git SHA;
- frozen C8.3a protocol fingerprint;
- evidence class `EV1_MEASURED_CPU_DISTRIBUTED_CORRECTNESS`;
- ordered layer/checkpoint rows;
- per-trace frozen comparisons;
- aggregate summary;
- topology-normalized scientific fingerprint.

Summary fields include trace count, layer/checkpoint row count, rankable trace count, semantic/state equivalence mismatch counts, expected-outcome mismatch count, per-layer opportunities and violations, explicit non-success count, physical replay failure count, and correctness-pass trace count.

## Evidence boundary

C8.3b observations are finite deterministic/real-CPU correctness observations. A zero observed violation count is not mathematical proof. No latency, throughput, CPU, memory, or scaling evidence from this slice may be used to adjudicate Gate G3.

## Exit

- all frozen C1/C2/C8 campaign mechanics have exact-head tests;
- the authoritative execution gate passes;
- two independent executions agree on scientific identity and summary;
- the canonical artifact is uploaded;
- bounded result review finds no protocol drift or evidence-class overclaim.

C8.3c performs independent re-adjudication and final result freeze.
