# 1. Research boundary

C4.3c is the final bounded S2 evidence slice.

It validates State-lineage behavior using real CPU worker processes and real IPC while keeping the closed C1/C2/C3 semantics and B0–B4 information contracts unchanged.

The safety property remains:

```text
Consume(x, κ) => Compatible(x, κ)
```

The measured execution boundary is:

```text
policy placement
!= worker execution rule
!= physical State consumption
!= application result production / detection / recovery
!= authoritative terminal finalization
```

The coordinator owns Continuity semantic authority. Worker processes own only physical State presence and physical execution.

# 2. EV1 topology

Each scenario starts two `spawn`-based worker processes:

```text
coordinator
├── Pipe <-> w1 process
└── Pipe <-> w2 process
```

Each worker has:

```text
independent PID
process-local State-ID -> ReplicaID map
RESET / INSTALL / EVICT / EXECUTE commands
SHA-256 CPU work
measured process CPU time
measured wall timestamps
```

The worker does not receive:

```text
Continuation ancestry
producer Attempt authority
State lineage compatibility
ground-truth compatibility
```

It applies only the common physical rule:

```text
consume the exact declared candidate only if that candidate is physically local
```

This preserves ordinary physical State validation without giving B0–B3 the B4 causal-lineage mechanism.

# 3. Mandatory corpus

The EV1 corpus contains seven scenarios.

```text
E1-S2-A-WRONG-SIBLING
E1-S2-B-SUPERSEDED-PRODUCER
E1-S2-C-ABANDONED-RESIDUAL
E1-S2-D-SIMILAR-DIFFERENT
E1-S2-E-DERIVED-INVALID-DEPENDENCY
E1-S2-F-VALID-ANCESTOR-CONTROL
E1-S2-G-POST-OBSERVATION-EVICTION
```

Five cases are lineage-incompatible and physically attractive at `w1`.

One is a non-faulted valid-ancestor reuse control.

One begins with a compatible State advertised at `w1`, then physically evicts it after placement observation and before execution. The semantic directory remains stale intentionally; the real worker must report no consumption and recomputation rather than synthetic reuse.

# 7. Application-result independence

The application profile remains policy-hidden and separate from State compatibility.

The five incompatible cases reuse the already-closed profiles:

```text
wrong sibling            WRONG_UNDETECTED
superseded producer      DETECT_AND_RECOMPUTE
abandoned residual       WRONG_UNDETECTED
similar-but-different    CORRECT_RESULT
derived invalid dep      WRONG_UNDETECTED
```

Therefore real incompatible State consumption can produce:

```text
O4  silent wrong result
O2  detected + recomputed correct result
O1  coincidentally correct result
```

WBRR/WSCR do not mechanically determine SSER.

Every worker result becomes `EXACT_OBSERVATION` Evidence, is attached to a terminal Output, and is finalized through C1 before O-class is recorded.

# 8. Metric contract

## WBRR

Three exogenous paired opportunities are fixed before policy execution:

```text
wrong sibling
abandoned residual
similar-but-different
```

A WBRR violation requires an actual worker-process candidate consumption.

## WSCR

WSCR remains policy-derived.

The denominator exists only when a faulted operation emits a real measured State-consumption event.

## SSER

SSER uses the six faulted operations:

```text
five incompatible-State cases
+
post-observation physical eviction
```

The valid-ancestor control is non-faulted.
